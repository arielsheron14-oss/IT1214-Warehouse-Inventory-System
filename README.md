# IT1214-Warehouse-Inventory-System

This is a simple Java Program to manage a warehouse_Inventory using The ArrayList.

Here,We can be able to

Add new items to the inventory,
Remove the Items from the inventory,
Update the Latest stocks Available in the inventory,
Search items by using their ID or their name,
Display all items and their details.

To Execute the Code 
We have to compile the code using the command "javac Warehouse.java " and after we can run it using the command "java Warehouse" in the cmd.
